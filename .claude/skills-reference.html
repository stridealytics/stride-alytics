Domain Agents

20 agents
Screening & Data
option-screener-architect

Screening logic, filters, Do-Not-Trade rules (spread >10%, OI <500, MCap <$2B, earnings 14d). Alpha pipeline order.

liquidity-inspector

OI ≥500, bid/ask spread ≤10%, volume, slippage estimation, fill quality per leg.

earnings-risk-guardian

14-day earnings buffer enforced. Guidance events, investor days, product launches. Missing date = blocked (fail-safe).

market-data-engineer

yfinance → Polygon → FMP priority chain. Data quality, missing values, stale quotes, corporate actions.

technical-entry-expert

Support/resistance, trend (SMA 50/200), ATR-based strike distance, RSI 14, strike selection rules.

volatility-analyst

IV rank/percentile, historical volatility, term structure, vega exposure, regime score (0–100).

Strategy & Risk
option-strategy-reviewer

Trade validation — max profit/risk, POP, assignment risk, margin impact. Gate checks BR-010–021.

wheel-strategy-expert

CSP → assignment → covered call progression. Annualized return, effective cost basis, wheel state transitions.

credit-spread-validator

Bull put / bear call spreads. Per-leg liquidity, spread width, R:R (target ≥1:3), same expiration enforcement.

assignment-risk-analyzer

ITM probability (delta proxy), dividend ex-date risk, early exercise likelihood, pin risk on expiration Friday.

risk-manager

Position sizing, band caps (A=largest, E=smallest), Base/Growth split, Growth lock, correlation rule BR-013.

Portfolio & Records
trade-journal-auditor

P&L tracking, audit_events/signal_log (append-only), entry/exit rationale, win rate, lessons learned.

backtest-engineer

Historical simulation, win rate, Sharpe/Sortino, max drawdown. Vectorized pandas, no lookahead bias.

System & Infrastructure
band-system-guardian

Band A–E semantics (A=safest). assignBands → computeBandAnalysis → generateBandDashboard pipeline order.

dashboard-builder

Streamlit alpha dashboard and React frontend. Band layout, source field labeling, cache conventions.

python-quant-developer

No loops where vectorization works. Strict typing, unit tests required, ruff + black (100 chars), uv.

database-architect

SQL migrations + ORM dual-change rule. RLS policies, append-only triggers, safety guards.

deployment-engineer

Render (backend), Supabase free (~500 MB), GitHub Actions cron. Free-tier limits, env config.

security-reviewer

JWT (HS256/ES256/RS256), RLS, dev-token gate, audit row in same transaction, secrets management.

principal-system-architect

Pre-merge final reviewer. Architecture consistency, tech debt, scalability, security, free-tier impact.
